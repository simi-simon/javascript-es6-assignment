# JavaScript Basics & ES6 Assignment

Solutions to all 9 JavaScript questions.

## Requirements
- Node.js (or a browser console)

## Run

### Run all solutions at once:
```bash
node solutions.js
```

### Run an individual program:
```bash
node 01-print-numbers.js
node 02-sum-array.js
node 03-find-largest.js
node 04-even-or-odd.js
node 05-reverse-string.js
node 06-merge-arrays.js
node 07-filter-even.js
node 08-template-literals.js
node 09-arrow-function.js
```

## Programs Covered
1. `01-print-numbers.js` - Print numbers from 1 to 10 using a loop.
2. `02-sum-array.js` - Return the sum of an array.
3. `03-find-largest.js` - Find the largest number in an array.
4. `04-even-or-odd.js` - Check whether a number is even or odd.
5. `05-reverse-string.js` - Reverse a string.
6. `06-merge-arrays.js` - Merge arrays using the spread operator.
7. `07-filter-even.js` - Filter even numbers using ES6 `filter()`.
8. `08-template-literals.js` - Use a template literal to create a welcome message.
9. `09-arrow-function.js` - Rewrite `greet()` as an arrow function.
